# V23 · Form completion

- Servicio sigue siendo obligatorio.
- Para Invitación digital, Tipo de evento ahora es obligatorio.
- Tipo de evento es un selector e incluye “Otro”.
- Si se elige “Otro”, aparece un campo adicional obligatorio para especificarlo.
- Después de enviar aparece una pantalla clara: “Tu solicitud fue enviada”.
- Si el usuario dejó correo, la pantalla indica que recibió confirmación por email.
- Si no dejó correo, indica que MAEM puede responder por WhatsApp.
- El usuario puede pulsar “Enviar otra solicitud”; el formulario se limpia y vuelve al paso 1.
- Apps Script y backend no cambian.
