# V25 · Portfolio flow

## Home
- Ya NO muestra la demo ni un proyecto destacado.
- La home funciona como puerta de entrada a:
  - Invitaciones digitales
  - Páginas web
  - Procesos
- Mantiene acceso global a /proyectos/.

## Invitaciones digitales
- Incorpora una sección real de portafolio / mini case study.
- Muestra la demo de boda en contexto.
- Incluye:
  - explicación breve;
  - preview en vivo;
  - funciones principales;
  - CTA para ver la demo;
  - CTA para solicitar una invitación;
  - enlace al portafolio general.

## Arquitectura
La intención es replicar el mismo patrón más adelante:
- /paginas-web/ → portafolio web
- /mejora-de-procesos/ → casos de procesos
- /proyectos/ → portafolio general de MAEM
