Términos y Condiciones

Última actualización: agosto de 2026

Estos términos regulan el uso del sitio web de MAEM Studio y las solicitudes de cotización enviadas a través de él. El envío de una solicitud no constituye por sí mismo una contratación ni genera una obligación de pago.

1. Servicios

MAEM Studio ofrece servicios creativos y digitales, incluyendo invitaciones digitales, páginas web sencillas, apoyo en mejora de procesos y otros servicios acordados individualmente con cada cliente.

2. Cotización y contratación

El alcance, precio, entregables, revisiones, fechas y condiciones específicas de cada proyecto se definirán en una cotización o acuerdo previo. Un proyecto se considerará contratado cuando las partes acepten dichas condiciones y, cuando corresponda, se realice el pago inicial acordado.

3. Pagos

MAEM Studio puede aceptar pagos con tarjetas Visa y Mastercard mediante Poket, de forma presencial o a distancia. Este sitio web no contiene un formulario de pago y no solicita, procesa ni almacena números de tarjeta, fechas de vencimiento, PIN o códigos CVV.

4. Entregas, cambios y colaboración

Los tiempos de entrega dependen del alcance del proyecto y de que el cliente suministre oportunamente la información, materiales y aprobaciones necesarias. La cantidad de revisiones incluidas se indicará en cada cotización.

5. Cancelaciones y reembolsos

Las condiciones de cancelación y cualquier reembolso se determinarán según el estado del proyecto, el trabajo ya realizado y los gastos de terceros que hayan sido asumidos. Ninguna disposición de estos términos pretende limitar derechos que correspondan al consumidor conforme a la normativa aplicable.

6. Contenido proporcionado por el cliente

El cliente declara que tiene autorización para utilizar los textos, fotografías, logotipos, marcas u otros materiales que entregue a MAEM Studio para la ejecución de su proyecto.

7. Propiedad intelectual y portafolio

Los derechos de uso o entrega del trabajo final se definirán en la cotización correspondiente. MAEM Studio no publicará como caso de cliente información privada o material sensible sin autorización. Las demos creadas por MAEM Studio podrán mostrarse como trabajo propio.

8. Servicios de terceros

Algunos proyectos pueden utilizar proveedores externos de alojamiento, correo, mapas, formularios, pagos u otras herramientas. La disponibilidad y condiciones de esos servicios también dependen de sus respectivos proveedores.

9. Contacto

Para consultas relacionadas con estos términos: maemstudionic@gmail.com.

MAEM Studio opera inicialmente como persona natural en Nicaragua. Antes del lanzamiento definitivo conviene completar nombre legal y domicilio del responsable.

Política de Privacidad

Última actualización: agosto de 2026

Esta política explica qué información recibe MAEM Studio cuando una persona utiliza el formulario de cotización y cómo se utiliza esa información.

1. Datos que podemos recibir

  • Nombre.
  • Teléfono o WhatsApp.
  • Correo electrónico.
  • País.
  • Información sobre el evento, negocio, proyecto o proceso.
  • Fecha objetivo, presupuesto aproximado y fuente por la que conoció MAEM Studio.
MAEM Studio no solicita a través de este sitio números de tarjeta, fecha de vencimiento, PIN ni código CVV.

2. Finalidad

Los datos se utilizan para recibir la solicitud, analizar el proyecto, responder al interesado, preparar una posible cotización y mantener un registro básico de solicitudes y clientes.

3. Herramientas utilizadas

Para operar el formulario y las comunicaciones, MAEM Studio puede utilizar servicios tecnológicos de terceros, incluyendo herramientas de Google para hojas de cálculo, automatizaciones y correo electrónico, así como servicios de alojamiento web.

4. Conservación

Los datos se conservarán únicamente durante el tiempo razonablemente necesario para atender la solicitud, gestionar la relación con el cliente y cumplir obligaciones aplicables. Cuando ya no sean necesarios, podrán eliminarse o anonimizarse.

5. Compartición

MAEM Studio no vende los datos personales recibidos mediante este formulario. La información puede ser tratada por proveedores tecnológicos necesarios para prestar el servicio o cuando exista una obligación legal.

6. Comunicaciones promocionales

El envío de una cotización no implica consentimiento para recibir publicidad periódica. Si en el futuro se ofrecen comunicaciones promocionales, se solicitará el consentimiento correspondiente de forma separada.

7. Derechos y contacto

Para solicitar acceso, corrección, actualización o eliminación de información personal relacionada con una solicitud, podés escribir a maemstudionic@gmail.com.

Cookies y tecnologías similares

Última actualización: agosto de 2026

MAEM Studio procura mantener una experiencia sencilla y utilizar únicamente las tecnologías necesarias para que el sitio funcione y pueda medirse técnicamente.

1. Cookies publicitarias

Actualmente MAEM Studio no configura desde este sitio cookies propias destinadas a publicidad comportamental o a construir perfiles comerciales del visitante.

2. Servicios externos

El sitio puede cargar recursos o contenidos alojados por terceros. Esos proveedores pueden recibir información técnica básica de conexión conforme a sus propias políticas.

3. Cambios futuros

Si MAEM Studio incorpora en el futuro herramientas no esenciales de analítica, publicidad o seguimiento que requieran consentimiento, esta política y el mecanismo de consentimiento del sitio deberán actualizarse antes de activarlas.

4. Contacto

Para consultas sobre esta política: maemstudionic@gmail.com.
